# Changelog

## 0.1.0

- First release of Claudle Jump as an OpenCode V2 TUI plugin (OpenCode 2.0.20+).
- `/jump` panel with the shared game engine, highscore and a sidebar line.
- Pauses with a banner and toast when the agent finishes; subagents are ignored.
- Release asset `claudle-jump-opencode.tar.gz` with `install.sh` and `install.ps1`.
